# Renewal Radar — free demo

Everything that charges you on a schedule, on one calm screen. This is the complete app: every
screen, every feature, no entry limit and no watermark.

The demo keeps nothing after you close the tab. Saving your data, installing it as an app,
reminders and export are what buying turns on.

It runs entirely in your browser. There is no server, no account, and nothing is uploaded —
including any bank statement you hand it.

_This folder is a build. The source lives elsewhere._
